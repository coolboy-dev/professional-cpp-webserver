Core Architecture

Event-Driven I/O

Leverages Linux epoll for non-blocking I/O multiplexing, allowing thousands of concurrent connections with minimal overhead.

Scale-Out Threading

Dynamic thread pool separates request acceptance from processing, maximizing CPU utilization across all available cores.

Intelligent Caching

Embedded LRU cache with TTL expiration reduces disk I/O and provides sub-millisecond response times for hot assets.

Hardened Security

Integrated path traversal protection, token-bucket rate limiting, and strict MIME type validation.
